# Gujarat Scientific and Polymer

A modern web platform for PTFE products, lined valves, glass equipment and industrial hardware — trusted by chemical, pharma and process industries across India.

## Features

- Product catalog with detailed categories
- Industrial solutions showcase
- Company information
- Contact and inquiry system
- Responsive design for all devices

## Tech Stack

- React + TypeScript
- Vite for fast development
- Tailwind CSS for styling
- React Router for navigation
- Radix UI components

## Getting Started

1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Build for production: `npm run build`
